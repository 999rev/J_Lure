# castwindow-web

面向南宁/广西的路亚出钓窗口期气象评分、河道结构标点分析与高德一键导航手机端网页（基于 Cloudflare Pages + Pages Functions 免服务器部署）。

## 部署方式

1. 将本仓库推至 GitHub。
2. 在 Cloudflare 控制台选择 **Workers & Pages -> Create -> Pages -> Connect to Git**。
3. 选择本仓库，Framework preset 选 `None`，Build command 留空，Output directory 填 `/`，点击 **Save and Deploy** 即可。
